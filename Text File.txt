You are an expert full-stack engineer and AI architect tasked with building a production-ready, lightweight hackathon MVP called "ArogyaSetu" (Multilingual Voice-First Health & Hospital Locator).

Build this system completely from scratch with a clean, cohesive structure:
- **Backend:** FastAPI (Python 3.10+)
- **Frontend:** Lightweight React (Vite + Tailwind CSS + Lucide Icons)

- **Data Source:** Static mock database for Latur, Maharashtra (`latur_hospitals.json`)
- **Speech & Location:** Native Web Speech API (STT & TTS) + Browser HTML5 Geolocation API

C. Geo & Haversine Distance (backend/geo.py)
Implement the Haversine formula to compute the distance in kilometers between the user's coordinates (user_lat, user_lon) and each hospital in Latur:
 * Function: find_nearest_hospitals(user_lat, user_lon, required_specialty=None, limit=3)
 * If user coordinates are outside Latur or null, default fallback origin to Latur City Center (18.4088, 76.5604).
 * Filter hospitals based on whether required_specialty matches any entry in available_treatments (or return nearest general emergency facilities if no specific specialty is required).
D. Triage & Gemini Integration (backend/triage.py)
Implement an asynchronous function process_medical_query(user_query: str, language: str):
 * Rule-Based Emergency Guardrail: First, perform a fast regex check for emergency keywords in English, Hindi, and Marathi (e.g., chest pain / छातीत दुखणे / सीने में दर्द, severe bleeding / रक्तस्त्राव / खून बहना, unconscious / बेशुद्ध / बेहोश). If triggered, instantly flag is_emergency: True.
 * Gemini Flash Structured Triage:
   * Prompt Gemini Flash to act as an empathetic triage assistant.
   * Output strict JSON with:
     * analysis: Concise, empathetic explanation of possible non-definitive causes (never give definitive medical diagnoses or prescription drug dosages).
     * urgency: "EMERGENCY", "CONSULT_TODAY", or "HOME_CARE".
     * specialty_needed: One matching department tag from our database (e.g., "Cardiology", "Orthopedics", "General Medicine", "Pediatrics").
     * recommended_action: What the patient should do right now in simple steps.
     * response_text: Localized conversational response in the requested language (mr, hi, or en).
     * disclaimer: Standard clinical disclaimer that this is an AI tool and not a doctor.
E. API Endpoints (backend/main.py)
 * POST /api/chat: Accepts { message: str, language: "en"|"hi"|"mr", lat: float, lon: float }. Runs triage, queries geo.py for matching hospitals, and returns the combined triage analysis, localized text, and ordered list of nearest relevant hospitals.
 * GET /api/hospitals: Returns the raw list of all hospitals with filtering by specialty.
 * GET /api/health: Healthcheck endpoint.
